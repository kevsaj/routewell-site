# routewell.ca

Source for [routewell.ca](https://routewell.ca), the website for Routewell: fixed-price Microsoft 365 automations for small firms in Ontario.

Plain HTML and CSS with no build step.

## Run locally

```
python3 -m http.server 8000
```

Then open http://localhost:8000. Links are root-relative (`/demo/`), so open the site through the server rather than as a file.
